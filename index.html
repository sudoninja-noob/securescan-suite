Three Scanners

Everything in one file

Each scanner is fully isolated — separate drop zones, separate results, separate exports

📦
SBOM Scanner
Manifest Analysis

Parses package manifest files and generates a full Software Bill of Materials with CVE cross-reference, license breakdown, and CycloneDX 1.5 / SPDX 2.3 output.

  • npm, PyPI, Maven, Go, Rust, Cargo ecosystems
  • NVD · OSV · GHSA vulnerability cross-reference
  • License compliance grid (permissive / copyleft / proprietary)
  • Policy gate — CVSS ≥ 9.0, GPL in prod, no fix available
  • CycloneDX 1.5 JSON preview with syntax highlighting
  • Export: HTML · Excel · CSV · JSON · SPDX · CycloneDX · PDF
🔬
SCA Scanner
Binary / Installer Analysis

Fingerprints executables and installers against a database of 80+ known software products to identify embedded third-party libraries and associated CVEs.

  • .exe · .msi · .dmg · .apk · .jar · .deb · .rpm and more
  • 80+ product fingerprints (Wireshark, OpenSSL, PuTTY, Zoom…)
  • Risk score 0–10 with visual bar
  • Detected component tags with versions and licenses
  • NVD deep links for every CVE finding
  • Export: HTML report · Excel (3-sheet workbook)
📡
Firmware Scanner
Component Extraction

Performs deep component extraction from firmware images — ELF binaries, shared libraries, package databases, config files, and startup scripts — and maps known CVEs.

  • 21 components extracted on every scan
  • Device type detection (router, IP camera, IoT, NAS, OTA…)
  • Hardcoded credential flags from /etc/passwd + /etc/shadow
  • One-click Firmware → SBOM pipeline feed
  • Architecture tab + SBOM Feed tab
  • Export: HTML · Excel (4-sheet) · CSV · JSON · XML

Features

Built for security engineers

No install. No backend. No data leaves your machine.

⚡
Zero Setup
Open the HTML file and start scanning immediately. No Node, no Python, no Docker, no cloud account.
🔒
100% Client-Side
All analysis runs in your browser. No files are ever uploaded. Safe for sensitive firmware and proprietary manifests.
📊
Multi-Format Export
HTML, Excel (.xlsx), CSV, JSON, XML, SPDX 2.3, CycloneDX 1.5 — each scanner exports independently.
🔗
Firmware → SBOM Pipeline
One-click feed extracted firmware components into the SBOM scanner. Complete end-to-end workflow.
🎯
Policy Gates
Automated PASS/FAIL checks — no CVSS ≥ 9.0, no GPL in production, all components have a fix available.
🔍
NVD Deep Links
Every CVE links directly to nvd.nist.gov for full advisory detail, CVSS vector, and CWE mapping.
📈
Visual Charts
Vulnerability severity distribution bar charts and license type breakdowns per scanner.
🌙
Professional Dark UI
Color-coded scanner identities (teal / cyan / magenta), no distracting UI chrome.
📄
CycloneDX 1.5 Output
Standards-compliant SBOM generation readable by Dependency-Track, OWASP and other SBOM consumers.
